# Cambodia Open Data Atlas

A map explorer for the ODC Cambodia WMS catalogue, the supplied SEZ dataset, and the ODC/YEAC SME directory. Run a static HTTP server in this directory to preview it. The map loads OpenStreetMap tiles and ODC layers over the network. ODC layer availability and licences vary. The catalogue is a snapshot; the underlying ODC layers are not bundled.

SEZ points are derived from the source coordinates and are not zone boundaries. SME records contain no coordinates: SME markers represent approximate province centres. Google searches for individual businesses should be checked before travelling.

The GitHub Actions workflow deploys to Pages when the repository's Pages source is set to GitHub Actions.
